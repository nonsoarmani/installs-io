# Express Install: order checklist (one page)

Customer: ____________  Email: ____________  Date paid: ______  Due: ______

## 1. Intake (within a few hours)
- [ ] Payment shows in your Paystack dashboard
- [ ] Intake form received (site URL, platform, tool, access method). If not, email them the /thanks/ link
- [ ] Confirm scope matches the service terms (one tool, one site). If bigger, tell them before starting
- [ ] Reply to confirm the start time

## 2. Access
- [ ] Customer invited us as collaborator / staff with the minimum permissions
- [ ] No main passwords received. If one was sent, tell them to change it
- [ ] Access works: log in and note what we can see

## 3. Before changing anything
- [ ] Backup or duplicate theme / site (Shopify: duplicate theme; Webflow: backup; WordPress: host backup)
- [ ] Screenshot current state
- [ ] Check for existing copies of the tool (avoid double tracking)

## 4. Install
- [ ] Follow the matching guide on installs.io step by step
- [ ] Note any step that differed from the guide (fix the guide afterward)

## 5. Test
- [ ] Run every "How to test it's working" item in the guide
- [ ] Test on mobile
- [ ] Save proof: screenshots or short screen recording

## 6. Deliver
- [ ] Email: what we did, proof, anything they need to do next, how to remove our access
- [ ] Ask them to remove our access
- [ ] Note the revision window end date: ______

## 7. After
- [ ] Update the guide if anything changed (new `lastVerified` date only if you really re-verified)
- [ ] Record: time spent ______  problems ______
